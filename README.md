# Grok Build Install

One-click installer for Grok Build (xAI terminal coding agent).

## Easiest way (GitHub)
1. Open: https://github.com/Jgillihan106/grok-build-install
2. Click the green **Code** button → **Download ZIP**
3. Unzip it
4. Double-click `install-grok.command` (macOS) or run `install-grok.sh` in a terminal

## Or just run this in your terminal
```bash
curl -fsSL https://raw.githubusercontent.com/Jgillihan106/grok-build-install/main/install-grok.sh | bash
```

After install, type `grok` to start. First launch signs you in via browser.
